Cybersecurity Projects

Focused work in authorized assessment and Linux detection engineering.

C / LINUX / PROCFSRS
Prototype · Heuristic detector

Reverse Shell Detector

A Linux command-line prototype written in C. It enumerates processes through /proc, reads process metadata, and applies rule-based scoring for executable paths in temporary directories, deleted executables, selected parent process names, and selected executable names.

It reports process-level heuristics only; the current version does not inspect network connections, correlate sockets, block activity, or provide real-time protection.
